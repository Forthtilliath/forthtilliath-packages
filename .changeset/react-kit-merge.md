First release. Merges the deprecated `@forthtilliath/react-hooks` (`useKeyListener`, `useToggleState`) and `@forthtilliath/react-ui` (`Show`, `Repeat`, `SlotOrCallback`) into a single package, named to mirror `@forthtilliath/react-native-kit`. No behavior change to the hooks/components themselves — build switched from `tsup` to `tsc` for consistency with the rest of the monorepo.
