Eight new themes under `styles/themes/` that go well beyond a color swap: `brutalist`, `pixel`, `crt`, `synthwave`, `glass`, `sketch`, `newspaper`, `memphis`. Besides their own fonts, radius and shadows, each adds signature effects — plain CSS on shadcn's `data-slot` attributes (pixel frames, scanlines, perspective grid, frosted glass, hand-drawn outlines, double rules, confetti…), active only while the theme is imported; focus stays visible. Every text/background pair meets WCAG AA in light and dark mode. Fonts fall back to system stacks — load the ones named at the top of each file for the full look.
